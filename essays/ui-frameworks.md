*If HTML and CSS was like building a house, Bootstrap is like playing the sims*

From construction site to sandbox, UI frameworks give you every template you need to create beautiful web pages. UI frameworks such as the one I have recently learned about, Bootstrap, are in fact complicated and can take lots of time and energy to use effectively and efficiently. That being said, they exist for a reason: convenience. After gaining familiarity and experience with a UI framework, developers can streamline their webpage development while still having a wide variety of options, from creative and colorful, to boring and mundane, to everywhere in between. 

## Training Arc

Trivially, in order to build proficiency at Bootstrap, I had to, of course, get some practice. At the moment I first attempted to use Bootstrap, my most relevant experience had been about a week of learning and developing in raw HTML and CSS. The first noticeable advantage to Bootstrap was that it required dramatically less code to implement features. Because of Bootstrap's pre-built, template style, I was able to create a responsive navigation bar with just a few lines of code.
```
<nav class="navbar navbar-expand-lg navbar-dark bg-dark">
  <div class="container-fluid d-flex justify-content-evenly">
    <ul class="navbar-nav">
        <li class="nav-item">
          <a class="nav-link" href="#introduction">Introduction</a></li>
            <li class="nav-item"> 
           <a class="nav-link" href="#ie">Internet Explorer</a></li>
          <li class="nav-item">
            <a class="nav-link" href="#firefox">Firefox</a></li>
            <li class="nav-item">
              <a class="nav-link" href="#chrome">Chrome</a></li></ul>
```
And it came out looking like this.
<img width="300px" class="rounded float-start pe-4" src="../img/brahhhdah.png">
To build the same navigation bar in raw HTML and CSS would require far more lines of code and overall more work, time, and effort. This efficiency gain, without some sort of quality drop-off, is why I can see the value in frameworks like Bootstrap. Personally, in my limited experience, I found it convenient to work with once you get the right class declarations, and you can implement high-quality webpage features quite easily.

## So... Is it Worth it?

All of that sounded fine and dandy, but there are still some drawbacks to using a UI framework like Bootstrap. For example, due to the template style of Bootstrap, you do lose the luxury of instant customizability since you're working within the framework's classes. To unlock full creative liberty, your code can get very messy very quickly, having to override CSS rules and styles which can be a cumbersome ordeal or repetitive. It can also feel imitative, as there can be potential similarities in your project's appearance and other Bootstrap-based programs. On top of that, learning the classes and knowing when to use certain ones to make your project is a handful, and requires a great deal of dedication and practice to code fluently and with confidence.


## Final Takeaways

All things considered, in my opinion, Bootstrap 5 is a fantastic tool, and UI frameworks can be advantageous in general, depending on the task at hand. If your mission doesn't include “make the most unique original website ever,” then a UI framework could be a helpful resource that gets the job done in a more efficient way. On a situational basis, and with proper capability in a given framework, the benefits can be massive. So I’d say, before starting a given project, have a framework (or frameworks) you’re fluent in to take into consideration, so that when the situations arise, you can take some of the weight off your back and allow the beauty of UI frameworks to do the heavy lifting.
